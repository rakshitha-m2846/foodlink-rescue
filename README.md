# 🍽️ FoodLink Rescue

## 🚀 Overview
FoodLink Rescue is a web platform designed to reduce food waste by connecting restaurants with NGOs and volunteers.

## 💡 Problem
Large amounts of food are wasted daily while many people lack access to proper meals.

## ✅ Solution
This platform allows restaurants to list surplus food, enabling NGOs and volunteers to collect and distribute it efficiently.

## ✨ Features
- Add food donations
- View available listings
- Search by location
- Delete listings
- Clean and responsive UI

## 🛠️ Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS, JavaScript
